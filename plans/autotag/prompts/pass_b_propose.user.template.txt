- NEW_CATEGORY_MIN_COMBINED={{NEW_CATEGORY_MIN_COMBINED}}

Existing categories JSON:
{{EXISTING_CATEGORIES_JSON}}

Unknown entity profiles JSON:
{{UNKNOWN_ENTITY_PROFILES_JSON}}

Cluster hints JSON:
{{CLUSTER_HINTS_JSON}}

Instructions:
1) Create up to MAX_NEW_CATEGORIES coherent proposals.
2) Each proposal must include valid members selected from UNKNOWN_ENTITY_PROFILES_JSON.
3) Compute coverage to match the members in that proposal.
4) cohesion_score must be in [0, 1].
5) nearest_existing entries should compare to existing categories.
6) If ENABLE_TITLE_REGEX is false, return rule_tokens.title_regex as [].
7) Return all ungrouped unknown entity_ids in left_unassigned_entity_ids.
